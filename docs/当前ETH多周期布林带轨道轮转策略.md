# 当前ETH多周期布林带轨道轮转策略

## 策略身份

```text
策略：BOLLINGER_RANGE 4.0.0
品种：ETH/USDT
周期优先级：5m → 15m → 30m → 1h
模式：Mac本地影子模拟
LIVE_TRADING=false
Gate订单提交：关闭
```

## 周期选择

程序从高到低按以下顺序寻找震荡箱体：

1. 5分钟震荡，使用5分钟开仓和管理；
2. 5分钟没有震荡时，寻找15分钟震荡，使用15分钟开仓和管理；
3. 15分钟也没有震荡时，寻找30分钟震荡，使用30分钟开仓和管理；
4. 30分钟也没有震荡时，寻找1小时震荡，使用1小时开仓和管理；
5. 四个周期都没有震荡时不开仓。

高优先级周期存在有效震荡箱体时，即使尚未触轨，也不会同时使用低优先级周期开仓。

## 各周期箱体阈值

所有周期均使用20周期、2倍标准差布林带，并要求最近连续3根本周期K线的上轨、中轨、下轨分别保持走平。

| 周期 | 连续确认时间 | 每条轨道最大漂移 | 布林带最小宽度 |
|---|---:|---:|---:|
| 5m | 15分钟 | 1 USDT | 5 USDT |
| 15m | 45分钟 | 2.5 USDT | 5 USDT |
| 30m | 90分钟 | 3 USDT | 5 USDT |
| 1h | 3小时 | 3 USDT | 5 USDT |

另外要求成交量不超过最近20根平均成交量的2倍，且没有连续两根收盘价位于本周期布林带外。

## 全局单持仓

四个周期共享同一个影子账户：

- 全局最多只能存在一笔仓位；
- 有多单时禁止再开空单或其他周期仓位；
- 有空单时禁止再开多单或其他周期仓位；
- 当前仓位必须先减仓或完全平仓，之后才能建立相反方向；
- 到达对侧轨完全平仓后，如果原周期开箱仍有效，可以在同周期立即反手。

## 开仓与退出

每个被选中的周期都使用本周期轨道：

```text
触及本周期上轨 → 做空
触及本周期下轨 → 做多
到达本周期中轨 → 减仓50%，剩余仓位保护到开仓价
到达本周期对侧轨 → 全部止盈，可在同周期反手
```

同一根K线同时穿越上下轨时，由于无法确定先后顺序，保守跳过开仓。

## 止损和恢复

```text
初始固定止损：5 USDT
单笔风险预算：当前影子权益的0.25%
每日亏损2%：当天停止新开仓
最大回撤8%：永久停止新开仓
```

某个周期止损后只暂停该周期。该周期重新连续3根K线满足箱体条件后恢复；其他没有被暂停的周期仍可按优先级参与选择。

## 执行成本

```text
轨道限价挂单费率：-0.01%
止损市价吃单费率：0.075%
止损不利滑点：0.02%
```

上下轨开仓、中轨减仓和对侧轨止盈按限价成交模拟，止损按市价成交模拟。

## 数据时序

每个周期只使用上一根已经收盘的本周期K线锁定轨道，再用下一根本周期K线的OHLC检查是否触轨。程序不会使用本根最终收盘后才知道的轨道值。

当前仍是K线收盘后的影子成交推算，不是Gate TestNet真实委托和撮合。
