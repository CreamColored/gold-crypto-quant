# 已归档：ETH 15分钟布林带轨道轮转策略（V3）

> 本文档描述已经停止的 `3.0.0` 版本。当前活动版本为多周期 `4.0.0`，请阅读
> [当前ETH多周期布林带轨道轮转策略](当前ETH多周期布林带轨道轮转策略.md)。

## 1. 策略信息

| 项目 | 当前设置 |
|---|---|
| 策略名称 | `BOLLINGER_RANGE` |
| 策略版本 | `3.0.0` |
| 交易品种 | `ETH/USDT` |
| 合约类型 | USDT永续合约行情 |
| 主周期 | 15分钟 |
| 当前模式 | Mac本地影子模拟 |
| Gate订单提交 | 关闭 |
| `LIVE_TRADING` | `false` |

当前策略不交易BTC，不使用5分钟开仓，不使用EMA，也不使用ADX作为开仓过滤条件。

## 2. 布林带参数

```text
周期：20
标准差倍数：2
上轨：中轨 + 2倍标准差
中轨：最近20根收盘价的平均值
下轨：中轨 - 2倍标准差
```

所有交易判断只使用已经收盘的15分钟K线。

处理下一根K线时，使用上一根已收盘K线计算出的布林带价格，避免使用本根收盘后才知道的数据。

## 3. 箱体确认

最近连续3根已经收盘的15分钟K线必须同时满足：

1. 上轨在这3根K线中的最高值与最低值之差不超过2.5 USDT；
2. 中轨在这3根K线中的最高值与最低值之差不超过2.5 USDT；
3. 下轨在这3根K线中的最高值与最低值之差不超过2.5 USDT；
4. 布林带总宽度至少为5 USDT；
5. 当前成交量不超过最近20根平均成交量的2倍；
6. 没有出现连续两根收盘价位于布林带外。

3根15分钟K线相当于至少观察45分钟，不是只比较相邻两根K线。

满足上述条件后，程序将行情标记为箱体候选，并允许轨道轮转交易。

## 4. 开仓规则

箱体有效时：

```text
价格触及上轨 → 卖出做空
价格触及下轨 → 买入做多
```

例如，上一根已经收盘的15分钟K线上轨为2,460：

```text
下一根K线最高价达到2,460 → 按2,460模拟做空
```

如果同一根15分钟K线同时穿过上轨和下轨，由于无法从OHLC确定先后顺序，程序保守跳过，不开仓。

## 5. 中轨处理

持仓到达中轨后：

1. 平掉50%仓位；
2. 剩余50%继续持有；
3. 剩余仓位的保护止损移动到开仓价格。

保护止损移动到开仓价格并不代表最终完全不亏。保护止损按市价成交，还需要计算吃单手续费和不利滑点，所以剩余半仓可能产生少量亏损。

## 6. 对侧轨止盈与反手

多单路径：

```text
下轨开多 → 中轨减仓50% → 上轨全部止盈
```

空单路径：

```text
上轨开空 → 中轨减仓50% → 下轨全部止盈
```

到达对侧轨全部止盈后，如果箱体仍然有效，则在同一轨道立即反手：

```text
多单到上轨止盈 → 立即做空
空单到下轨止盈 → 立即做多
```

## 7. 止损规则

初始固定止损距离为5 USDT：

```text
2,450做多 → 初始止损2,445
2,450做空 → 初始止损2,455
```

如果同一根K线同时可能触发止损和止盈，程序采用保守顺序，优先按止损发生处理。

如果刚刚触轨开仓，同一根15分钟K线继续向不利方向运行并越过5点止损，立即记录同根K线止损。

## 8. 止损后的暂停

发生止损后：

1. 当前箱体失效；
2. 暂停新开仓；
3. 等待重新连续3根15分钟K线满足箱体候选条件；
4. 满足后才恢复交易。

该规则用于避免以下连续亏损：

```text
下轨做多 → 止损 → 价格继续下跌 → 再次做多 → 再次止损
```

## 9. 箱体突破

连续两根收盘价位于布林带外时，确认箱体突破：

- 停止新的反向开仓；
- 等待重新形成稳定箱体；
- 已存在的持仓继续由止损、中轨和对侧轨规则管理。

单根插针或单根轻微越轨不会立即确认突破。

## 10. 仓位与单笔风险

每笔交易的风险预算为当前影子权益的0.25%。

假设当前权益为10,000 USDT：

```text
风险预算 = 10,000 × 0.25%
         = 25 USDT
```

程序综合以下成本反推ETH开仓数量：

- 5点固定止损；
- 轨道挂单费率；
- 止损吃单费率；
- 止损不利滑点。

当前每笔通常约为3.5 ETH。随着影子权益变化，实际数量会自动变化。

当前影子账户没有实际使用125倍杠杆，仓位完全按照风险预算计算。

## 11. 手续费与滑点

当前影子模拟参数：

```text
轨道限价挂单费率：-0.01%
止损市价吃单费率：0.075%
止损不利滑点：0.02%
```

负挂单费率表示模拟返佣。

| 动作 | 模拟成交方式 |
|---|---|
| 上下轨开仓 | 限价单 |
| 中轨减仓 | 限价单 |
| 对侧轨止盈 | 限价单 |
| 初始止损或保护止损 | 市价单，计算吃单费和滑点 |

## 12. 账户级风控

```text
每日亏损达到2% → 当天停止新开仓
历史最大回撤达到8% → 永久停止新开仓
禁止补仓
禁止同一根K线同时猜测两个方向
```

止损和平仓管理优先于新开仓判断。

## 13. 当前影子模拟流程

```text
Gate测试网行情
    ↓
Mac读取已收盘15分钟K线
    ↓
本地判断箱体、触轨和突破
    ↓
本地记录虚拟开仓、减仓和平仓
    ↓
计算仓位、手续费、滑点和盈亏
    ↓
发送交易或异常邮件
```

影子账户不是Gate TestNet账户：

- Gate网页不会显示这些委托和持仓；
- 程序不会调用Gate订单提交接口；
- 所有资金、仓位和盈亏都保存在Mac本地；
- 不涉及真实资金。

## 14. 执行时序限制

当前程序会等待15分钟K线收盘后，再检查该K线的最高价或最低价是否触及上一根锁定的轨道。

因此：

- 邮件通常比K线标注时间晚约15分钟；
- 成交是根据完整OHLC推算的影子成交；
- 不能验证Gate测试网真实排队、部分成交、撤单和断线订单恢复。

## 15. 当前已知问题

1. 短时间走平后突然单边突破，仍可能在下轨做多或上轨做空，并在同一根K线止损；
2. 箱体识别还不能完全复现人工选择箱体的能力；
3. 中轨减仓后的保护止损邮件目前可能显示为“固定5点止损”，实际成交逻辑是开仓价保护止损；
4. 当前策略30天回测仍未达到正式准入条件，只适合继续影子观察；
5. 当前没有接入Gate TestNet订单提交。

## 16. 安全状态

```text
LIVE_TRADING=false
真实交易关闭
Gate测试网订单提交关闭
当前仅运行Mac本地影子模拟
```
