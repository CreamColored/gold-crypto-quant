对照对象是 `course-mac` 分支上**正在跑的 V5.8**
（`multi_timeframe_rotation_simulator.py` + `strategy/bollinger_range.py`），
课程材料只取 `/Users/stephen/Documents/Codex/2026-09-04/you/outputs/` 下的 .md。

本分支只做震荡，不做顺势，所以核心是**第八课（箱体震荡交易技巧）**，
其余各课只取与箱体相关的部分。

## 一、V5.8 现在实际在做什么（逐条从代码核出来）

| 环节 | 实现 | 位置 |
|---|---|---|
| 箱体资格 | 布林带三轨连续 3 根各自移动 ≤ 2.5×价格比例，且带宽 ≥ 5×价格比例，且量比 ≤ 2.0，且未突破 | `bollinger_range.py:233` |
| 价格缩放 | `price_scale = 近20根收盘中位数 / 2500`，走平阈值与最小带宽都按它放大 | `simulator:232` |

| 止盈 | **当根 K 线的对侧轨**（`main["bb_upper"]`） | `simulator:1271,1358` |

## 二、课程要求而 V5.8 没有的（按对胜率的影响排序）

### 1. 止盈目标是移动的（L8R8）

课程：「从上沿你做的一个空……到达了下沿的位置，那要及时去止盈」——
目标是**一条固定的水平线**。

V5.8：`target = upper if old_side == "LONG" else lower`，`upper` 取自当根 K 线。
开多之后价格上涨，中轨抬、σ 又放大，**目标是双重后退的**。

实测：**49 小时内 0 次对侧轨止盈**。设计中的"下轨买→中轨减→上轨卖"几乎从不走完。

这是唯一一个"改动极小、影响极大"的点，且开仓时刻的对侧轨其实已经存在
`position.entry_opposite_band`（`simulator:992`），目前只当止损阶梯用。

### 2. 突破判定不看量、不看实体（L8R10 / R11 / R12 / R13）

课程给了四条并列条件：

| | 课程 | V5.8 |
|---|---|---|
| R10 | 突破 K 线**实体**收在沿外，影线刺出不算 | 用收盘价，不区分实体 |
| R11 | 成交量放大到箱体内的 **1.5–2 倍** | 完全不看 |
| R12 | MACD 柱逐根放大，量价同步 | 完全不看 |
| R13 | 回踩不破原沿，且**缩量**企稳 | 完全不看 |

V5.8 只有"连续 2 根收盘在轨外"。这比单根严格，但和课程是两个维度：
课程要的是**能量确认**，V5.8 要的是**持续性确认**。

对胜率的影响不在于少做几笔，而在于：**假突破时 V5.8 会取消箱体资格并停止交易，
真突破时它同样只是取消资格**。两种情况处理一样，等于放弃了 L8R14 那五类信号里
的全部信息。

### 3. 箱体没有"触碰次数"这个维度（L8R2 / R3 / R4）

课程：上下沿由**至少 2 次**高/低点连成的水平线，且「触碰的次数越多，
箱体的有效性也就越强」。

V5.8 的箱体是布林带走平，**没有触碰概念**。所有合格箱体权重相同。

这条直接关系胜率：课程认为触碰 2 次和触碰 8 次的箱体不是一回事，
而 V5.8 对两者一视同仁。

### 4. 箱体中部不操作，但 V5.8 在中轨减仓（L8R8）

课程：「在中轨的时候、中间位的时候是没有任何的操作」。

V5.8：`MIDDLE_REDUCE_RATIO = 0.30`，到中轨减 30%。

这是**直接冲突**。不过要说清楚：减仓是降风险动作，不是开新仓，
和课程禁止的"在中部开单"不完全是一回事。列在这里是因为它会削掉
一笔本可以走到对侧沿的单子的三成利润——在第 1 条修好之前看不出代价，
修好之后就会显现。

### 5. 没有位置分类（L8R5）

课程把箱体分低位（吸筹）、中位（洗盘）、高位（诱多出货），
「形态相同但位置不同，解释不同」。

V5.8 没有"位置"这个维度。高位诱多箱体和低位吸筹箱体做同样的高抛低吸。

课程自己没给低/中/高位的量化标准，所以这条**不可直接编码**，
但可以用一个代理量（比如相对近 N 根的分位）先做出观察标记。

### 6. 零轴完全没用（L10R6 / R11）

课程把零轴当强弱分水岭，L10R9 明说水下金叉只是弱势反弹。
V5.8 对 DIF 在零轴哪一侧毫无判断。

判据就是 `dif > 0`，改动成本最低的一条。

## 三、两套方案的评估

### 方案二（废弃 V5.8 重写）——不建议

理由不是工作量，是**这条路已经走过，结果更差**。

按第八课重写的震荡策略（水平沿、固定止盈、实体收盘突破、放量确认）
在 150 天币安数据上的实测：

```
580 笔   毛盈亏 +312.5U   手续费 -2166.7U   净 -1854.1U
样本外 148 笔   胜率 41%   -560.2U
144 组参数里，训练窗与样本外都为正的：0 组
```

**毛利是正的，手续费把它吃成了负的。** 每天 3.9 笔、每笔 3.74U 手续费，
150 天交了 2166U 手续费去换 312U 的毛利。

也就是说：换成课程的箱体定义**没有解决问题**，因为问题不在箱体怎么画，
在**交易频率 × 手续费**。重写一次只会再撞一次同样的墙。

### 方案一（优化 V5.8）——建议走这条，但要改变优先级

V5.8 值得保留的是那套已经验证过的基础设施：按风险反推仓位、VIP0 真实费率、
宏观静默窗口、日亏熔断与永久保险丝、状态持久化、Web 监管。这些重写要花的时间
远超策略逻辑本身。

但**不要按"补齐课程规则"的顺序改**。按实测影响排：

| 顺序 | 改动 | 依据 | 预期 |
|---|---|---|---|
| 1 | 止盈目标冻结为开仓时的对侧轨 | L8R8 | 让 0 次止盈变成正数，字段已存在 |
| 2 | 提高箱体门槛，**减少交易频率** | L8R4 触碰次数 | 直击手续费问题 |
| 3 | 突破加实体收盘 + 放量 1.5 倍 | L8R10/R11 | 减少假突破造成的止损 |
| 4 | 零轴过滤 | L10R6 | 成本最低 |
| 5 | 中轨减仓比例下调或取消 | L8R8 | 第 1 条生效后才有意义 |

第 2 条是关键，也是课程里最容易被忽略的一条。L8R4 说触碰次数越多箱体越有效、
「周期越大交易价值越高，周期越小骗线越多」——**这两句话都指向"少做但做对"**，
而 V5.8 每天 4 笔的频率是反着来的。

## 四、必须先回答的问题

上面所有改动的收益都建立在一个前提上：**单笔毛利要能盖过手续费**。

现在的数字是每笔 3.74U 手续费 vs 25U 风险预算（15%），加上入场滑价
（15m 收盘入场比触碰价平均差 0.19%，相当于再吃掉 20%），
两项合计已经占掉风险预算的三分之一。

所以在动策略之前，有三个方向要先定：

1. **降频**——只做触碰次数多的箱体，笔数从 3.9/天 降到 1/天以下
2. **提高单笔目标**——箱体太窄的不做（V5.8 有 `minimum_bandwidth`，但阈值没按手续费校准过）
3. **降低费率**——挂单 0.02% vs 吃单 0.05%，止盈用限价单已经是 maker，
   入场能否也改成挂单

这三条里任何一条不解决，补多少课程规则都会被手续费抵消。
