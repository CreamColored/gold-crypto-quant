# 币安 ETH 15分钟箱体策略：分钟级历史对照

一次冻结参数的探索性对照，没有找到正期望方案。固定箱体减少交易量，但全历史单笔表现没有改善；换色暂停也没有显示稳定优势。这不能证明朋友所有主观结构判断均无效，也不是线上策略完整回放。

## 冻结识别规则

共同使用BOLL(20,2)，总体标准差。

1. dynamic_flat：最近3根上下中轨各自极差不超过2.5美元，带宽至少6美元。它是简化动态轨对照，不是现有V5.9策略。
2. anchor：带宽至少6美元；收缩至过去20根最大带宽80%以下；中轨6根净漂移不超过当前带宽15%；过去12根至少两次跨中轨。成立后冻结当时上下轨作为箱体。
3. anchor_pause：在anchor基础上，最近两根15分钟线发生MACD柱正负切换时暂停新开仓。MACD为12/26/9。

箱体收盘越过固定边界3美元失效，或存续96根后到期；下一根收线之前不重建。不使用事后最低点、未来确认顶底背离或“有望形成结构”。

这次没有单独实现“正柱期间触下轨、负柱期间触上轨”的完整阶段识别，也没有多周期顶底结构豁免；它们不能被声称已验证。

## 相同的执行规则

- 每个分钟开始只读取已完成的15分钟K线；用其轨道测试本分钟高低价触轨，开盘已经在轨道之外或同分钟双轨同时触碰则跳过。
- 单仓，不加仓；固定箱体方案要求入场位仍在箱体边缘20%区域，且没有离开箱体3美元之外。
- 动态对照止损为入场参考轨道外3美元；固定方案为箱体边界外3美元；计入入场滑点后距离超过10美元则不做。
- 轨道在入场时冻结。到中轨减半、余仓止损移至实际入场价；若到中轨距离超过10美元，则提前2美元减半。余仓对轨止盈。
- 最长持仓24小时，区间结束平仓。止损后至少等下一根15分钟线收盘再考虑入场。
- 入场分钟允许止损但不记目标收益；后续分钟先检查止损，再检查减仓与目标。同分钟触发减仓与保本时按保守路径保本退出。
- 平仓当分钟不反手，下一分钟才重新判断，因此没有冒充秒级“立即反手”效果。
- 开平及减仓一律按成交额0.05%费用、0.02%不利滑点假设。这是统一研究成本，不是核验后的用户实际费率；没有计资金费。
- 每笔计划风险25 USDT，包含预计止损成交成本。没有复利、125倍杠杆或强平模型，没有日亏2%/回撤8%账户熔断；所得金额仅用于统一风险比较，不是某个本金可持续交易的账户收益。
- 胜率按整笔交易扣成本后的净盈亏计算，减仓不拆单。

## TradingView振荡指标增量检查

用户提供的TradingView链接是社区“震荡指标”观点聚合页，不是统一定义或经过验证的策略。另按TradingView官方说明复现了CHOP(14)、ADX(14)和BBW相对位置，并在同一回放器中只改变入场过滤条件：CHOP>=61.8、ADX<20、两者合取、排除过去252根中BBW最低10%、带宽3根增长不超过20%。

结果没有发现可直接上线的过滤器。以固定箱体为基线：

| 期间 | 基线：交易/PF | 加CHOP：交易/PF | 加ADX：交易/PF | CHOP+ADX：交易/PF |
|---|---:|---:|---:|---:|
| 2020—2022 | 2996 / 约0.44 | 615 / 约0.36 | 1541 / 约0.38 | 360 / 约0.31 |
| 2023—2024 | 2811 / 约0.24 | 522 / 约0.17 | 1321 / 约0.20 | 272 / 约0.13 |
| 2025—2026 | 2301 / 约0.26 | 435 / 约0.25 | 1208 / 约0.26 | 260 / 约0.19 |

表中分组PF为按年度盈利与亏损金额重新汇总后的近似值，不采用年度PF加权。所有组仍小于1。

另做了不涉及成交的“新箱体出现后8根15分钟线”检查。CHOP过滤把未来2小时同时到达箱体上下边缘的比例从约15%—18%提高到约21%—24%，但边界持续不破的比例由约49%—52%下降到约40%—44%。这解释了为何它看起来更像来回摆动，却没有改善交易PF：波动更活跃，触边更多，破位也更多。

因此下一版识别应把两个问题拆开，而不是继续把指标全部合取：

1. 区间存在分数：固定中心漂移、有效往返次数、CHOP只作为一项证据。
2. 边界失效风险：BBW极端挤压、BBW重新扩张、收盘靠近或越过固定边界、方向效率突然抬升。
3. 入场质量：触轨后的拒绝程度和剩余盈亏空间，独立于“是否震荡”。
4. 箱体生命周期：冻结形成时边界；随着证据衰减降低分数并失效，不把每根移动后的布林带当作新支撑压力。

当前运行代码虽然计算了ADX，但同周期轮转的box_candidate没有使用它；旧的严格15分钟识别才使用ADX<20。直接把ADX条件复制进去没有数据依据。本轮只改研究脚本和报告，没有修改运行策略。
