# 震荡策略前提验证：为什么 V5.8 / V5.9 都不赚钱

时间：2026-09-05 ~ 09-06
分支：`range-mac-v5.9`
数据：币安 USD-M 永续 BTC/ETH，2025-09-05 → 2026-09-05，官方月度归档（SHA-256 校验）

---

## 结论

**「价格触到布林带轨会回归中轨」这个前提，在这一年的 BTC/ETH 永续上不成立。**

不是参数没调好，不是震荡识别不够准。脱离策略直接检验：触轨之后价格**轻微地
继续朝突破方向走**，16 个测量格子里 14 个方向与均值回归相反。

V5.8 和 V5.9 都建立在这个前提上，所以两者都亏，V5.9 只是亏得慢。

---

## 一、证据链

### 1. V5.8 一年回放：−62.5%，但 94% 的窗口没有交易

第一次跑出 `−8.05%`，看着还行。查终态发现 **`permanent_fuse: True`** ——
8% 最大回撤熔断在**第 17–35 天**就烧了，剩下 330 天一笔没开。

```
[25,000 步] 权益 9,309U 回撤 6.9%  281 笔   ← 还没烧
[50,000 步] 权益 9,195U 回撤 8.05% 335 笔   ← 已经烧了
之后 47 万步，成交数一直是 335
```

熔断是永久的、没有恢复路径（`simulator.py:1630`）。所以那个 −8.05% 实际是
**「35 天亏 8%，然后冻结」**，当基线用不了。

把 `0.08` 提成 `MAX_DRAWDOWN_FUSE` 常量后关掉重跑，完整一年是 **−62.5%**。

### 2. 亏损集中在一类出场

一年 2,236 笔了结单：

```
固定保护止损        1052 笔  47%   -16,062U   每笔 -15.27U   均持仓 62 分
阶梯延续止损         499 笔  22%    +6,873U   每笔 +13.77U   均持仓 232 分
中轨减仓后保本止损    439 笔  20%      +474U   每笔  +1.08U
到达对侧轨止盈       202 笔   9%    +3,205U   每笔 +15.87U   均持仓 103 分
触轨开仓同分钟止损     44 笔   2%      -732U   每笔 -16.63U
```

**除「固定保护止损」外，其余合计 +9,820U。**这一类平均只持仓 62 分钟就被打掉，
即价格触轨后**直接穿过去**，不是在回归。

### 3. 用户人工标注揭示识别问题

用户在 2026-09-02 ~ 09-04 标注了三段震荡窗口（15m/30m/1h），
拿 V5.8 的 `box_candidate` 去对：

```
ETH 15m   命中 101   漏判 39   误判 73    精确率 58%
ETH 30m   命中  40   漏判 25   误判 19    精确率 68%
ETH 1h    命中   3   漏判  6   误判  6    精确率 33%
```

**15m 上它认定的箱体里 42% 是单边行情。**在那里做高抛低吸正是亏损来源。

用户指出的四个特征在数据上全部成立：

```
                 震荡      非震荡    区分度
带宽 %           0.95      1.94     0.49x
中轨穿越次数      5.11      2.99     1.71x
带宽变化 %      -9.25    +71.45     符号相反（收口 vs 开口）
MACD 柱体        0.44      0.78     0.56x
```

（一条修正：DIF 离零轴在 30m 上不区分（0.97x），只在 15m 有效。
另一条不成立：「同侧最长连续根数」没有区分度（0.81x / 0.94x）。）

### 4. V5.9 按这四条重写识别，改善来自「少做」而非「做得更好」

阈值从标注数据拟合，按周期分档。一年 A/B（唯一变量是识别）：

```
                      V5.8        V5.9        变化
最终权益            3,750U      5,879U     +2,129U
收益率              -62.5%      -41.2%      +21.3%
开仓笔数              2,285       1,168      -1,117
每笔期望             -2.79U      -3.58U      -0.79U   ← 变差
胜率                    45%         46%         +1%
固定止损笔数            1,052         512        -540
对侧轨止盈占比          8.9%       10.6%       +1.7%
```

**总收益改善 21 个百分点，但每笔期望反而变差。**改善全部来自笔数减半带来的
成本节省，不是单笔质量提升。

### 5. 成本结构：费前毛利本身就是负的

```
              台账净盈亏    交易成本    毛利（费前）
V5.8            -5,519U     5,200U       -320U
V5.9            -3,817U     3,283U       -534U
```

（台账合计与实际权益差约 10%，是收尾未平仓与个别缺字段事件造成的。）

### 6. 箱体质量不预测走完全程

对 V5.9 的 1,139 笔做后处理，按开仓时「箱体沿被验证过几次」分组：

```
按布林轨触碰数     笔数   走完全程率   每笔        相关系数 -0.034
  0-2             14      7.1%   -11.63U
  3-5             70     17.1%    -3.51U
  6-9            170     10.0%    -2.49U
  10+            885     10.4%    -3.37U

按水平沿触碰数     笔数   走完全程率   每笔        相关系数 +0.009
（课程 L8R2/R3）
  0               43      7.0%    -4.74U
  1               94     10.6%    -2.33U
  2              191     10.5%    -3.08U
  3+             811     11.0%    -3.46U
```

**两种口径都零相关。**课程 L8R4「触碰次数越多箱体有效性越强」在这批数据上不成立。

### 7. 直接检验前提——决定性证据

脱离策略，在所有触轨时刻测前瞻收益。正号=如预期回归，负号=继续突破：

```
                4根前瞻   8根    16根    32根     同期平均绝对波动
BTC 15m          -0.9    -1.6   -2.4    -0.7      30 ~ 89
BTC 30m          -1.4    -1.4   +2.3    -2.6      43 ~ 129
ETH 15m          -1.3    -2.2   -4.2    -3.1      42 ~ 125
ETH 30m          -3.5    -3.3   -1.7    -8.1      59 ~ 181
                                                  （万分之一）
```

样本：BTC 15m 有 9,672 次触轨 / 35,112 根 K 线。

**16 格里 14 格为负——触轨之后倾向于继续突破，不是回归。**

信号极弱（−2 ~ −4 个万分点 vs 同期 40~90 个万分点的波动），
解释力在 5% 以下，基本等于零，只是零的那一侧偏负。

## 二、被否掉的三条路

| 方向 | 结论 |
|---|---|
| 改挂单降成本 | **不存在这个杠杆**。`simulator.py:991` 开仓早就是 maker，减仓止盈也是 maker，只有止损走 taker+滑点（必须如此）。 |
| 收紧震荡识别 | V5.9 已证明：笔数降 49%、毛利降、成本降，**三者同比例缩小**，亏损结构原样保留。 |
| 按箱体质量筛选 | 两种触碰口径均零相关（−0.034 / +0.009）。 |

三条都堵死，原因相同：**它们都在优化一个不存在的信号。**

## 三、过程中的三处更正

记下来是因为它们都曾被当作结论用过一段时间。

1. **手续费高估 2.7 倍。**先前用「名义额 × 0.1%」（吃单往返）估算，
   但开仓与减仓止盈都是 maker 0.02%，只有止损是 taker。
   由此得出的「毛利是正的 +7,701U，被手续费吃光」是错的——
   **费前毛利本身就是负的**。

2. **「0 次对侧轨止盈」是小样本假象。**49 小时窗口里确实 0 次，
   据此推断一年也接近 0；实际一年是 202 次、占 9%。

3. **一个月回测的胜率提升是窗口特例。**当时 V5.9 胜率 46%→57%、
   每笔期望改善，据此说「剩下的单子质量更高」；
   一年数据显示胜率只涨 1%、每笔期望反而变差。

## 四、限定条件

结论限定在：**2025-09 ~ 2026-09、BTC/ETH 永续、币安、BOLL(20,2)、15m/30m/1h**。
换品种、换周期、换参数、换市场阶段都可能不同。

一个反向启发：既然触轨后倾向于继续走，**顺着突破方向做在同一位置上是正期望的一侧**
（虽然幅度小、未必盖得过成本）。这与课程第八课的「真突破四条件」（L8R10–R13）
方向一致。
