## 〇、先更正一条：这套课不是纯趋势跟随

我在只读完前六节时写过"课程教的是顺势持有、和现有的震荡策略是相反的"。
**读完第八课后这句话不成立**——第八课整节（59 分钟）讲的就是箱体高抛低吸：
上沿只做空、下沿只做多、到对侧及时止盈、不扛单。和现有策略是同一个赛道。

课程真正的结构是两套玩法并存，由**位置和大周期趋势**决定用哪套：

```
先判大周期趋势（L1 浪形 / L12 4小时）
├── 有明确趋势 → 顺势：回调低吸 / 反弹高空（L7R12、L7R13、L12R9）
├── 箱体震荡   → 高抛低吸，只做超短线（L8R6–R8）
└── 三角收敛   → 不做，等突破方向（L9R1）
```

这条改变了下面第五节的方向选择：课程自己给的答案就是"先有状态判据，
再决定用哪套策略"，也就是原来的 A 方案。

## 二、L2 顶底结构：与 `_structure_confirmed()` 的三处差异

（此节结论与上一版相同，L10 读完后新增第 4 条）

### 差异 1：缺少趋势前提

L2R5 要求顶部钝化必须"当前处于上涨趋势"，L2R8 底部钝化要求"当前处于下跌趋势"。
现有实现**完全没有检查趋势**，只比较相邻柱区的收盘价与 DIF。
横盘里也会判出"顶部结构"，而课程认为那不成立。

### 差异 2：缺少"至少两根"的浪形门槛

L1R1："最少要有两根线才能当作是一个浪形……只有一根时不单独计为一个浪形，
而视为前一段的延续"。

现有 `_histogram_groups()` 对任何长度的同色段都算一组，**包括只有一根的**。
单根柱的噪声会被当成独立浪形参与比较。

### 差异 3：三个阶段被压成了一个

课程把顶部结构分三步（L2R5/R6/R7）：

```
1. 顶部钝化    上涨趋势 + 价格创新高（收盘价） + DIF 未创新高 + DIF 尚未向下转折
2. 初步形成    钝化成立后，首次 DIF[t] < DIF[t-1]
3. 完全确认    再之后 DIF 下穿 DEA（死叉）
```

并明确"没有钝化，就不可能会有结构"（L2 42:08）。
现有实现只在**死叉那一根**判定，相当于第 3 步，缺第 1 步前提和第 2 步信号。

### 差异 4（读完 L10 后新增）：完全不用零轴

L10R6 把零轴定为强弱分水岭，L10R9 明说**水下金叉只是弱势反弹、不是趋势反转，
做多要快进快出**；L10R11 要求多周期都在零轴同侧才算共振。

现有策略对 DIF/DEA 在零轴哪一侧毫无判断，水下照样按震荡逻辑开多。
这是这十三节里**改动成本最低、语义最明确**的一条过滤：判据就是 `dif > 0`。

### 一致的部分

- 相邻峰比较（L2R2）——现有取 `groups[-2], groups[-1]` ✓
- 用最高/最低**收盘价**而非影线（L2R3）——现有用 `close.max()/min()` ✓
- 只用已收线 K 线（L2R4）——现有走 `is_closed=True` ✓

## 三、L8 箱体：课程的箱体和布林带箱体不是一回事

这是十三节里最该看的一节，因为它和现有策略做的是同一件事。

### 3.1 边界的定义完全不同

| | 课程（L8R1–R3） | 现有策略 |
|---|---|---|
| 上沿 | ≥2 个高点在同一价格附近的**水平**连线 | 布林带上轨 |
| 下沿 | ≥2 个低点在同一价格附近的**水平**连线 | 布林带下轨 |
| 插针 | **明确剔除**，不作锚点 | 无此概念 |
| 随时间 | 固定不动 | 随波动率逐根移动 |
| 有效性 | 触碰次数越多越强（L8R4） | 用带宽/斜率判平坦 |

**关键差异是"水平"**。课程的上下沿是历史上真实被反复拒绝的价格，
布林带轨道只是统计带，价格靠近上轨不代表那里有阻力。

### 3.2 这可能解释了"49 小时 0 次对侧轨止盈"

之前实测：49 小时内一次对侧轨止盈都没有，设计中的"下轨买→中轨减→上轨卖"
几乎从不走完。

L8R8 要求"上沿空单到下沿及时止盈"——**目标价是一条固定的水平线**。
查了现有代码，止盈的触发价和成交价用的都是**当前这根 K 线的轨**：

```python
upper = float(main["bb_upper"])          # 每根 K 线重算
target_hit = position.position_side == "LONG" and float(minute_bar["high"]) >= upper
target = upper if old_side == "LONG" else lower
```

也就是说开多之后价格上涨，上轨同步上抬，**止盈目标一直在往前跑**。
布林带上轨 = 中轨 + 2σ，而上涨本身既抬中轨又放大 σ，目标是双重后退的。

值得注意的是，**开仓时刻的对侧轨其实已经存下来了**：

```python
# multi_timeframe_rotation_simulator.py:992
position.entry_opposite_band = 2.0 * middle_reference - reference
```

但它目前只当止损阶梯的一档用，没有当止盈目标用。
所以"把止盈目标从当前轨换成 `entry_opposite_band`"是个**已有字段的复用**，
改动比想象中还小，可以直接回测验证 0 次止盈是不是移动目标造成的。

### 3.3 现有策略完全没有的：突破与假突破

课程用了整整半节讲箱体**失效**时怎么办，现有策略这块是空的。

真突破四条件（L8R10–R13，必须同时满足）：

1. 突破 K 线**实体收盘**在沿外（只有影线刺出、实体收回不算）
2. 成交量放大到突破前的 **1.5–2 倍**
3. MACD 柱逐根放大，且量价同步
4. 回踩不有效跌破原沿，且回踩**缩量约一半**

假突破五类（L8R14，任一成立）：

1. 盘中冲出但收盘留长上影、实体回箱内
2. 突破没有明显放量（未达 1.5–2 倍）
3. 价格创新高但 MACD 柱缩短 / 小周期出顶部结构
4. 盘中放量但收盘为阴线、滞涨
5. 首根看似有效，次根冲高回落收回箱内，或放量阴包阳

止损（L8R17）：**入场后 K 线实体有效收回箱内 → 无条件止损离场。**

对现有策略的直接含义：现在的"止损封锁"是事后的（打了止损才封锁 symbol）。
课程的做法是**事前**的——箱体被有效突破的那一刻，箱体判定本身就作废，
不该再有下一笔高抛低吸。这比事后封锁更早，也不会像现在这样把整个 symbol
锁住很久（BTC/ETH 从非农那两笔停到现在）。

### 3.4 位置分类（L8R5，不可编码但要记）

低位箱体多为吸筹，中位为洗盘，**多轮拉升后的高位箱体大概率是诱多出货**。
形态一样、位置不同，含义相反。系统没有"位置"这个维度。

## 四、L12 多周期：层级 vs 平铺，这是架构级差异

课程（L12R1–R6）：

```
战略周期 4h   → 只定方向，不给买卖点
战术周期 1h   → 只给候选区域，不给精确点
执行周期 15m  → 在该区域内才找入场信号
三者方向一致 = 共振，才下单（L12R14）
4h 趋势破位 → 下面所有 1h/15m 策略全部失效（L12R15）
```

现有实现（`ENTRY_INTERVAL_PRIORITY = ("15m", "30m", "1h")`）：

```python
for interval in ENTRY_INTERVAL_PRIORITY:
    main = confirmed_context_at(symbol, interval, minute_open_time)
    ...  # 谁先合格谁开仓
```

**这是平铺的优先级列表，不是层级**：15m 合格就开，不问 1h 什么方向。
课程要求的是 15m 必须服从 4h。

另外两点：

- **L12R5 要求周期间隔 4–6 倍**。现有 15m/30m/1h 是 2 倍、2 倍，
  属于课程点名的"周期过于接近"（视频举的反例是 1m/5m/15m，性质相同）。
  课程的稳健组合是 **4h / 1h / 15m**（4 倍、4 倍），
  激进组合是 **1h / 15m / 5m**。
- 现有系统**根本没有 4h 数据**。要走这条路先得加 4h K 线。

## 五、L11 洗盘/诱多：一条已经验证了现有功能

L11R12 四句口诀：

> 量能不跟随时不追高；影线太长时已有仓位要离场；出现顶背离时不加仓并考虑减仓；
> **消息发布后先观望，不依消息直接下单。**

最后一句正是 2026-09-04 非农那两笔亏掉 49.36U 之后加的
`macro_blackout` 宏观静默窗口（NFP/CPI/FOMC 前后各 15 分钟）。
课程独立给出了同一条规则，**这个功能可以留**。

L11R13 的四项验证顺序（量→K线→背离结构→位置）可以作为将来任何形态判据的检查清单。

## 六、L13 仓位管理：现有实现已经对了

这节是唯一"课程规则 = 现有代码"的一节，核对结果：

| 课程规则 | 现有实现 | 结论 |
|---|---|---|
| L13R9 `开仓数量=(总资金×风险比例)÷(止损点数×每点价值)` | `position.quantity = state.equity * risk_per_trade / loss_per_unit` | **同一个公式** ✓ |
| L13R1 单笔风险 1%–2% | `risk_per_trade = 0.0025`（0.25%） | 比课程更保守 ✓ |
| L13R7 无关键位时用固定点数止损 | BTC 300 点 / ETH 12 点固定止损 | 正是这条 ✓ |
| L13R6 技术止损放前低/前高 | 结构单按结构位止损 | ✓ |
| L13R4 **永远不要用交易所最大杠杆** | `PAPER_LEVERAGE = 125.0` | 名字吓人，见下 |
| L13R14 连续亏损强制暂停 | 有日亏熔断 + 永久保险丝 | 机制上覆盖 ✓ |

关于 `PAPER_LEVERAGE = 125.0`：实测它**不参与仓位计算**，只用于山寨币止损距离
换算和日志里的收益率展示。按现值算实际名义杠杆：

```
权益 9836.60U × 风险 0.25% ÷ 止损 300 点 = 0.08197 BTC
名义 0.08197 × 79800 = 6541U ÷ 9836U = 0.66 倍
```

**实际不到 1 倍杠杆，不违反 L13R4。** 但常量名有误导性，建议改名。

## 八、讲者自己强调的限制（比规则更重要）

- **信号不等于必然**："有了信号，能不能够去做单呢？显然是不行的"（L2 23:56）
- **结构可重复出现**："有可能做一、二、三，甚至是更多"（L2 39:28）——
  顶底结构不保证反转
- **3/7 战法只用于单边**："不适合用除了单边行情以外的其他任何行情"（L3 51:50）
- **斐波那契不能定方向**："它不能作为判断方向"（L5 04:00）
- **K 线不能单独用**："永远不要单独地用小周期的一个K线去做决策"（L6 56:25）
- **MACD 不能单独开仓**（L10R15）：柱体强弱、金叉死叉只辅助判断，
  由弱转强需同时看到金叉 + 越过零轴 + 突破下跌趋势
- **周期越小骗线越多**（L8R4）：现有策略主力在 15m，课程认为交易价值低于大周期
- **箱体内只做超短线**（L8R8）："不扛单、不期待箱体内出现大行情"
- **全程未给任何胜率或盈亏比**：讲者反复说"大概率"，没有一个数字

## 九、下一步（待你决定）

课程本身已经回答了"趋势还是震荡"的问题：**先判状态，再选策略**。
所以原来的 A/B/C 里，A 和 B 其实是同一条路的两个深度。

按"改动量 ÷ 预期收益"排序，**都还没做**：

1. **止盈目标冻结**（3.2）——不引入任何课程新概念，只改一行取值时机，
   直接验证"0 次对侧止盈"是不是移动目标造成的。**建议先做这个。**
2. **零轴过滤**（L10R6）——判据明确无歧义，改动极小。
3. **L1R4/R5 趋势过滤器**——用系统已有的 MACD 柱体分组即可实现，
   是"当前是趋势、别做震荡"的直接答案，非农那两笔正是它该挡住的。
4. **箱体作废替代止损封锁**（L8R17）——解决当前 BTC/ETH 被长期锁死的问题。
5. **L2 补趋势前提 + 两根门槛**——会改变现有行为，须回测对照。
6. **4h 层级共振**（L12）——工作量最大，且需要先接 4h 数据。

每一条实现前先把`【视频未明确】`里影响判断的空缺问到你这里，
落地后走固定窗口回测对照，**默认关闭，数据支持才开**。
