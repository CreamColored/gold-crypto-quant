## 一、这套课教的是趋势跟随，和现有策略是相反的

现有策略是**布林带震荡箱体轮转**：下轨买、上轨卖，赌均值回归。

课程教的是**顺势持有、破位离场**，而且第一课有一句直接指着这个软肋：

> "所有的亏损都是逆势操作的结果"（L1 17:48）

2026-09-04 非农那两笔正是这个：价格跌破下轨，停留确认判定"触碰有效"开多，
而那不是回归，是趋势启动。课程框架会说：那是逆势。

**所以这不是"给现有策略加过滤器"那么简单，要先定方向：**

| | 含义 | 代价 |
|---|---|---|
| A 当刹车 | 保留震荡策略，加"当前是趋势就别开仓"的闸 | 最小，直接补上今晚暴露的洞 |
| B 双策略 | 震荡与趋势各跑一套，按状态切换 | 需要可靠的状态切换判据，而那本身最难 |
| C 替换 | 放弃震荡箱体，改做趋势跟随 | 推倒重来，两周对照数据作废 |

**尚未决定。**

## 二、和现有代码的三处具体差异（最有价值的部分）

系统里 `_structure_confirmed()` 已经实现了顶底结构，但和第二课的定义不同。

### 差异 1：缺少趋势前提

课程 L2R5 要求顶部钝化必须"当前处于上涨趋势"，L2R8 底部钝化要求"当前处于下跌趋势"。

现有实现**完全没有检查趋势**，只比较相邻柱区的收盘价与 DIF。

意味着：横盘里也会判出"顶部结构"，而课程认为那不成立。

### 差异 2：缺少"至少两根"的浪形门槛

L1R1：

> "最少要有两根线才能当作是一个浪形……只有一根时不单独计为一个浪形，
> 而视为前一段的延续"

现有 `_histogram_groups()` 对任何长度的同色段都算一组，**包括只有一根的**。
单根柱的噪声会被当成独立浪形参与比较。

### 差异 3：三个阶段被压成了一个

课程把顶部结构分三步（L2R5/R6/R7）：

```
1. 顶部钝化    上涨趋势 + 价格创新高（收盘价） + DIF 未创新高 + DIF 尚未向下转折
2. 初步形成    钝化成立后，首次 DIF[t] < DIF[t-1]
3. 完全确认    再之后 DIF 下穿 DEA（死叉）
```

并且明确 **"没有钝化，就不可能会有结构"**（L2 42:08）。

现有实现只在**死叉那一根**判定，大致相当于第 3 步，但：
- 没有第 1 步的钝化前提
- 没有第 2 步这个更早的信号

课程的第 2 步比第 3 步早若干根 K 线，这是"左侧交易"的入场依据（L2R12/R14）。

### 一致的部分

- 用**相邻峰**比较（L2R2）——现有代码取 `groups[-2], groups[-1]`，是相邻的 ✓
- 用**最高/最低收盘价**而非影线（L2R3）——现有代码用 `close.max()/min()` ✓
- 只用已收线 K 线（L2R4）——现有代码走 `is_closed=True` ✓

## 四、讲者自己强调的限制（这部分比规则更重要）

- **信号不等于必然**：`"有了信号，能不能够去做单呢？显然是不行的"`（L2 23:56）
- **结构可重复出现**：`"有可能做一、二、三，甚至是更多"`（L2 39:28）——
  顶底结构不保证反转，可以连续出现多次
- **3/7 战法只用于单边**：`"不适合用除了单边行情以外的其他任何行情"`（L3 51:50）——
  **这条直接排斥现有的震荡策略场景**
- **斐波那契不能定方向**：`"它不能作为判断方向"`（L5 04:00）
- **K 线形态不能单独用**：`"永远不要单独地用小周期的一个K线去做决策"`（L6 56:25）
- **满足条件越多越确定，但没有概率**：讲者反复说"大概率"，全程未给任何胜率或盈亏比

## 五、下一步该做什么

按价值排序，**都还没做**：

1. **L1R4/R5 的趋势过滤器**——用系统已有的 MACD 柱体分组就能实现，
   是"这不是震荡，别开仓"的直接答案。今晚非农那两笔正是它该挡住的。
2. **补上 L2R5 的趋势前提**——现有顶底结构缺这一条，改动小但会改变行为，须回测对照。
3. **L1R1 的两根门槛**——同上，须回测。
4. **L2 的三态拆分**——把现有布尔量拆成钝化/初步/确认，工作量大，收益需要先验证。

每一条实现前都要先把`【视频未明确】`里影响判断的空缺问到你这里，
落地后走固定窗口回测对照，默认关闭，数据支持才开。
